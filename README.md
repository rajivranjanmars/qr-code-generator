# QR Code Generator

A small Python command-line program that asks for a URL and saves its QR code to `qr.png`.

## Getting started

Install `qrcode[pil]` in a Python virtual environment, then run `python main.py`. Enter a URL at the prompt; the output is saved as `qr.png`.
